# ฐานข้อมูลเบื้องต้น | สื่อนวัตกรรมดิจิทัลเพื่อใช้แก้ปัญหา

สื่อ CAI (บทเรียนออนไลน์แบบหน้าเดียว) สอนพื้นฐานฐานข้อมูล 5 เรื่อง:
1. ความรู้เบื้องต้นเกี่ยวกับฐานข้อมูล
2. การสร้างตารางเก็บข้อมูล
3. การจัดการข้อมูล และตาราง
4. การสร้างคิวรีเบื้องต้น
5. การสร้างแอ็กชันคิวรี

มีระบบเข้าสู่ระบบ, แบบทดสอบก่อน/หลังเรียน (จับเวลา 20 วิ/ข้อ), เนื้อหาความรู้แบบแท็บ,
เกมจับคู่คำศัพท์, ระบบตรวจสอบคะแนนและพัฒนาการ, และระบบออกจากระบบ (ล้างข้อมูลใน Local Storage)

## เล่นเกม
เปิดไฟล์ `index.html` ในเบราว์เซอร์โดยตรง หรือผ่านลิงก์ GitHub Pages หลัง deploy

## เปิดใช้งานผ่าน GitHub Pages
1. ไปที่ repo settings → Pages
2. Source เลือก branch `main` โฟลเดอร์ `/ (root)`
3. รอสักครู่แล้วเข้าลิงก์ที่ GitHub สร้างให้ (เช่น `https://<username>.github.io/<repo-name>/`)

## หมายเหตุ
ข้อมูลผู้เรียน (ชื่อ, คะแนน) เก็บด้วย Local Storage ของเบราว์เซอร์เท่านั้น
หากเนื้อหา/คำถามมีการเปลี่ยนแปลงในอนาคต ให้ปรับค่า `CONTENT_VERSION` ในโค้ด
เพื่อล้างข้อมูลเก่าของผู้เรียนที่เคยทำแบบทดสอบเวอร์ชันก่อนหน้าโดยอัตโนมัติ
